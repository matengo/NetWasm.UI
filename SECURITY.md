# Security policy

## Supported versions

Security fixes go into the latest 0.x release.

## Reporting a vulnerability

Please report security issues privately through
[GitHub security advisories](https://github.com/matengo/NetWasm.UI/security/advisories/new),
not in public issues.

For how to use NetWasm.UI securely (Content Security Policy, Trusted Types, XSS), see
[docs/security.md](docs/security.md).
